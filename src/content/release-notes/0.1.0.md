# Genosai Voice 0.1.0

Первая версия Genosai Voice — голосовой диктовки с ИИ-исправлением текста.

- **Облачное распознавание по вашему API-ключу**: Gemini, OpenAI, Groq, ElevenLabs или любой OpenAI-совместимый адрес.
- **ИИ-корректор**: орфография, пунктуация, слова-паразиты и самопоправки исправляются автоматически.
- **Fn + Пробел** на Mac и **Ctrl + Win** на Windows — зажмите, говорите, отпустите.
- **Офлайн-режим** на локальных моделях — без интернета и без ключа.
