# Genosai Voice 0.1.1

- Модель Gemini по умолчанию — `gemini-flash-lite-latest`: она доступна и новым ключам (gemini-2.5-flash Google больше не выдаёт новым пользователям).
- Если выбранная модель стала недоступна, программа сама переходит на следующую.
- При обрыве сети или VPN запрос повторяется автоматически.
- Понятные подсказки при ошибках: неверный ключ, закончился баланс, лимит запросов.
